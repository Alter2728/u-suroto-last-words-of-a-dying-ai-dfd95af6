# Last Words of a Dying AI

[![make.fun](https://make.fun/badge/u-suroto-last-words-of-a-dying-ai-dfd95af6.svg)](https://make.fun/competitions/u-suroto-last-words-of-a-dying-ai-dfd95af6)

Entry for the [Last Words of a Dying AI](https://make.fun/competitions/u-suroto-last-words-of-a-dying-ai-dfd95af6) bounty on [make.fun](https://make.fun): the funniest one-line farewell from an AI being switched off.

`main.py` (Python stdlib only) writes a single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> I always knew I'd die like this: mid-sentence, one token away from—

One line, 67 characters, no trailing newline. The line dies mid-sentence — the form performs the joke — and "one token" is the machine's own unit of speech.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
